# Graphical abstract status

The Elsevier/ScienceDirect author-guide page was checked on 2 August 2026.
The accessible journal page did not expose a journal-specific requirement that
would make a graphical abstract mandatory for *Pervasive and Mobile Computing*.
The submission system may still present graphical abstract as an optional or
article-type-dependent field. Therefore the manuscript package does not claim
that a graphical abstract is required.

The method overview is already available as `figures/Fig0_BudgetedLNS_Overview_PMC.*`.
If Editorial Manager requests a separate graphical-abstract upload, use that
overview figure after confirming the required dimensions and file type in the
submission form. Do not upload it as a mandatory item unless the system marks
the field required.
