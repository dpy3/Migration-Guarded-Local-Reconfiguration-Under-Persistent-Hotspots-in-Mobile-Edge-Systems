# Migration-Guarded Local Reconfiguration Under Persistent Hotspots in Mobile Edge Systems

## Dataset and code package identity

- **Dataset title:** MGR-PH
- **Full dataset title:** Migration-Guarded Local Reconfiguration Under Persistent Hotspots in Mobile Edge Systems
- **Code and data package:** MGR-PH
- **Repository:** `dpy3/Migration-Guarded-Local-Reconfiguration-Under-Persistent-Hotspots-in-Mobile-Edge-Systems`

This repository contains the source code, simulator-generated data, analysis
scripts, figure source data, manuscript source, and checksum records associated
with the manuscript. The data are reproducibility outputs generated by the
provided simulator and experimental scripts; no separate external dataset was
used.

The main data products are stored under `data/` and include formal evaluation,
hotspot-onset evaluation, component ablation, sensitivity analysis, and
admission validation. The corresponding figure source data are stored under
`figures/`.

The reported migration metric counts admitted-to-admitted node changes.
Admission and rejection transitions are separately identified by the revised
runner when the per-task assignments are available. `MigrationMB` is a
profile-derived volume proxy and is not a packet-level network trace.

Target: *Pervasive and Mobile Computing* (Elsevier official `elsarticle.cls` source is under `manuscript/elsevier_official/`).

## Package map

- `code/Algorithms/`: M-CA-ALM, Budgeted-LNS, HIVE internal comparator, the public BigMEC adapter, and comparator solvers.
- `code/Environment/`, `code/Data/`, `code/Utils/`: simulator, hardware profiles and metric/repair utilities.
- `code/Run_Paper2_Revision.m`: principal MATLAB entry point for the frozen revision protocol.
- `code/analyze_paper2_revision.py`, `code/make_paper2_revision_figures.py`: analysis and figure regeneration.
- `data/`: formal, hotspot-onset, ablation and sensitivity CSV tables, including admission validation.
- `figures/`: canonical final figure exports and source-data CSV files.
- `manuscript/elsevier_official/`: current Elsevier source, bibliography, tables and PDF.
- `submission_docs/`: citation/claim audits, highlights, cover-letter draft, graphical-abstract status and author-completion checklist.

## Main entry points

1. Read `submission_docs/ENVIRONMENT_revision_source.md` and this README.
2. Configure MATLAB paths to include `code/` and subfolders.
3. Run `code/Run_Paper2_Revision.m` for the frozen protocol, or regenerate analysis/figures with the supplied Python scripts.
4. Map manuscript figures to the source-data files with the names `SourceData_Fig2...` through `SourceData_Fig7...`.

## Claim boundary

The current manuscript supports the tested N=180 setting, three persistent-hotspot profiles, the tested 1%/5%/10% budgets, and the implemented HIVE internal comparator. HIVE is not a published method or a bibliography entry. It does not claim cross-topology, real-deployment or universal budget optimality. `MigrationMB` and repair overrides retain the definitions stated in the manuscript and are not physical packet captures.
