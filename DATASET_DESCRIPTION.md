# Dataset Description

## Dataset title

MGR-PH

Full title: Migration-Guarded Local Reconfiguration Under Persistent Hotspots in Mobile Edge Systems

## Associated code and data package

MGR-PH

## Contents

The dataset consists of simulator-generated reproducibility outputs for the
manuscript submitted to *Pervasive and Mobile Computing*. It includes:

- formal run-level and slot-level results;
- hotspot-onset results;
- component-ablation results;
- migration-guard sensitivity results;
- admission-accounting validation;
- figure source-data CSV files; and
- checksum records for the code, data, figures, and manuscript sources.

## Data generation

The results are generated by the supplied MATLAB simulator and experiment
runner. The protocol uses 180 persistent tasks, five heterogeneous edge nodes,
200 slots, three persistent-hotspot scenarios, and 30 paired seeds per formal
scenario. The primary local-search setting is rho = 0.05, giving a trial-level
screening value B = 9.

## Metric definitions

`Migrations` counts only changes from one admitted edge node to a different
admitted edge node. `AdmissionTransitions` counts rejected-to-admitted
transitions, and `RejectionTransitions` counts admitted-to-rejected
transitions. `TotalPlacementStateTransitions` includes all three transition
types. `MigrationMB` is a profile-derived migration-volume proxy rather than a
packet-level transfer measurement.
