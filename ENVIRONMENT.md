# Paper 2 environment

- MATLAB: release compatible with the supplied `.m` files.
- Python: 3.x with NumPy, pandas, SciPy and Matplotlib for revision analysis and figure generation.
- LaTeX: TeX Live/MiKTeX with the included Elsevier `elsarticle.cls` and `elsarticle-num.bst`.
- The frozen revision package is simulator-based; no external service or private dataset is required.

Author-owned DOI, funding and identity fields remain unchanged and are not fabricated in this package.
